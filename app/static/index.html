Mobile Installation & Tailscale

1. On your Mac: Run python3 run.py in the repository.

2. Tailscale / LAN: Open your mobile browser and enter your Mac's IP (e.g., http://100.x.y.z:8000).

3. Install as Web App:

  • iOS (Safari): Tap the Share button → select Add to Home Screen.
  • Android (Chrome): Tap the three dots menu → select Install App or Add to Home Screen.
