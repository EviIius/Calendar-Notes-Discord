Mobile Installation & Tailscale

1. On your Mac: Run python3 run.py in the repository.

2. Tailscale / LAN: On your phone, visit your Tailscale IP (e.g., http://100.x.y.z:8000).

3. Install as Web App:

  • iOS (Safari): Tap Share → Add to Home Screen.
  • Android (Chrome): Tap Menu (...) → Install App.
